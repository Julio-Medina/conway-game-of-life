# Conway's Game of Life in C

A terminal-based implementation of John Conway's Game of Life written in C.

## Features

- Loads an initial pattern from a text file.
- Runs the simulation directly in the terminal.
- Interactive controls:
  - `q` quit
  - `+` increase speed
  - `-` decrease speed
  - `p` pause/resume
  - `n` step one generation while paused
  - `r` reset to initial state

## Build

make
